# Zero Trust Cloud Lab

A cloud-hosted full-stack security lab deployed on AWS EC2.

## Stack

- AWS EC2
- Ubuntu Server
- Docker
- Docker Compose
- NGINX reverse proxy
- Flask API
- PostgreSQL database
- GitHub Actions CI/CD

## Features

- Public frontend dashboard
- REST API backend
- PostgreSQL persistent storage
- Dockerized services
- Automated deployment with GitHub Actions

## Deployment

docker compose up -d --build
